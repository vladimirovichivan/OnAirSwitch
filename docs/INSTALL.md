# Установка и настройка OnAir Lamp (Windows 11)

Инструкция для получателя. Весь путь — 15–20 минут, права администратора не
нужны. Windows 10 поддерживается так же, отличий нет.

Если что-то пошло не так — раздел «Если не работает» в меню Пуск или
[`SUPPORT.md`](SUPPORT.md).

---

## 1. Что нужно заранее

- Компьютер с Windows 11 (или Windows 10) и доступом в интернет.
- Умная розетка Tuya, уже добавленная в приложение **Smart Life** и работающая
  из приложения.
- Компьютер и розетка — в одной домашней сети (не гостевой Wi-Fi).
- Файл установщика `OnAirLamp-Setup-1.0.1.exe` и, если он есть,
  `SHA256SUMS.txt` рядом.

Проверить контрольную сумму (необязательно): в PowerShell выполнить
`Get-FileHash .\OnAirLamp-Setup-1.0.1.exe -Algorithm SHA256` и сравнить с
`SHA256SUMS.txt`.

---

## 2. Установка

1. Запустить `OnAirLamp-Setup-1.0.1.exe`.
2. Если Windows покажет синее окно «Windows защитила ваш компьютер» — нажать
   **Подробнее** → **Выполнить в любом случае**. Это нормально для программы без
   платной подписи.
3. Оставить галочку **«Запускать OnAir Lamp при входе в Windows»** и нажать
   **Установить**. Папку выбрать нельзя и не нужно: программа всегда ставится в
   `%LOCALAPPDATA%\Programs\OnAirLamp` — это личная папка пользователя.
4. По окончании установки оставить галочку **«Запустить OnAir Lamp»**: при
   первом запуске программа сама предложит настроить розетку. Если сейчас не
   готовы — в окне предложения нажать **Нет** и вернуться к разделу 3 позже.

В меню Пуск появится папка **OnAir Lamp** с четырьмя пунктами:

| Пункт | Зачем |
|---|---|
| OnAir Lamp | обычный запуск (он же автозапуск) |
| Настройка и проверка OnAir Lamp | мастер подключения розетки; если уже настроена — проверка или повторная настройка |
| Отчёт для поддержки | архив журналов без ключей |
| Если не работает | краткая диагностика |

В трее (рядом с часами) появится иконка лампы — возможно, в скрытых значках
`^`.

---

## 3. Настройка розетки

Мастеру нужны два значения из облака Tuya: **Access ID** и **Access Secret**.
Ключ самой розетки мастер получит сам и сохранит на компьютере; вводить его
вручную не нужно. Эти шаги делаются один раз.

### 3.1. Учётная запись Tuya IoT Platform

1. Открыть <https://iot.tuya.com> → **Sign Up**, тип аккаунта **Developer**,
   указать свою страну и подтвердить e-mail.
2. **Data Center** проекта должен совпадать с регионом аккаунта Smart Life. Для
   России на практике работает **Central Europe**.

### 3.2. Проект и подписки

1. `Cloud` → `Development` → **Create Cloud Project**.
2. Поля: **Industry** — `Smart Home`, **Development Method** — `Smart Home`,
   **Data Center** — как выше.
3. В мастере **Authorize API Services** оставить **IoT Core**,
   **Authorization Token Management** и **Smart Home Basic Service**, затем
   нажать **Authorize**. Кнопку **Skip** не нажимать: без подписок мастер
   настройки получит ошибку `1106 permission deny`.
4. Проверить: `Cloud` → `Service API` — у трёх сервисов статус `In service`.

### 3.3. Привязка Smart Life

1. `Cloud` → `Development` → проект → **Devices** →
   **Link Tuya App Account** → **Add App Account**.
2. Выбрать **Automatic Link (Recommended)** → **OK**.
3. Появится QR-код. В телефоне: **Smart Life** → профиль → сканер в правом
   верхнем углу → отсканировать код → подтвердить.
4. В таблице `Manage Devices` розетка должна быть со статусом `Online`. Если
   напротив неё `Link` — нажать `Link`. Если мешает лимит устройств, лишние
   устройства можно отвязать (`Unlink`).

### 3.4. Access ID и Access Secret

`Cloud` → `Development` → проект → **Overview** → скопировать **Access ID** и
**Access Secret** (кнопка «показать»).

Не отправляйте эти значения в чаты, письма и документы. При подозрении на
утечку перевыпустите их в том же окне.

### 3.5. Мастер: настройка и проверка

1. Открыть мастер. При первом запуске программа предложит это сама; позже —
   **Пуск** → **OnAir Lamp** → **Настройка и проверка OnAir Lamp** (или правый
   клик по значку лампы → **Настроить розетку…**).
2. Ввести **Access ID**, затем **Access Secret** (секрет при вводе не виден).
3. Мастер обратится к облаку, покажет список устройств и попросит выбрать
   розетку по номеру. Если розетка одна — она будет одна в списке.
4. Адрес в домашней сети мастер найдёт сам (UDP-поиск), запишет настройки и
   сразу проверит розетку: прочитает состояние, включит, выключит и вернёт как
   было. В конце — «проверка пройдена».
5. После успешной настройки приложение перезапустится автоматически — это
   ожидаемо. Дальше оно работает в обычном режиме (раздел 4).

Если в ответе ошибка `1106` — не авторизованы сервисы API: вернитесь к шагу 3.2
и нажмите **Authorize** (а не `Skip`), подождите минуту и повторите.

Если написано, что идёт встреча, — настройки уже сохранены, лампа будет
работать; проверка просто не переключала розетку в этот момент. Повторно
запустить проверку можно тем же пунктом меню: если розетка настроена, мастер
предложит выбрать между проверкой и повторной настройкой.

Повторная настройка нужна, если розетку заменили или перепривязывали в
**Smart Life** (ключ устройства меняется): в меню пункта «Настройка и проверка
OnAir Lamp» выберите **2. Настроить заново**.

## 4. Как это работает каждый день

- При входе в Windows приложение запускается само; в трее — иконка лампы.
- Началась видеовстреча в **Толке**, **Телемосте** или **Zoom** — лампа
  включается (обычно 1–3 секунды).
- Встреча закончилась — лампа выключается.
- Интернет и облако в повседневной работе не нужны: команды идут напрямую
  розетке по домашней сети.

Меню иконки в трее:

| Пункт | Что делает |
|---|---|
| Лампа: включена / выключена | текущее состояние и режим |
| Включить → на 1 час / на 2 часа / до конца дня / до ручного возврата | включить вручную на срок |
| Выключить → … | выключить вручную на срок |
| Автоматика по встречам | вернуть обычный режим |
| Снять автоматику → … | не трогать розетку на срок (диагностика) |
| Настроить розетку… | запустить мастер настройки |
| Открыть plug.log | журнал исполнителя |
| Выход | полностью выключить лампу: завершаются трей, наблюдатель и исполнитель |

---

## 5. Обновление

1. Запустить новый установщик. Он сам остановит работающую Лампу, поставит
   программу поверх старой, сохранив настройки розетки и журналы.
2. После установки запустить **OnAir Lamp** из меню Пуск (или перезагрузиться).

Закрывать трей вручную не нужно: скрытые процессы на запрос Windows «закрыть
приложение» не отвечают, поэтому установщик завершает их принудительно (только
процессы из папки установки, чужие Python не затрагиваются).

---

## 6. Удаление

1. **Параметры** → **Приложения** → **Установленные приложения** →
   **OnAir Lamp** → **Удалить** (или `unins000.exe` в папке установки).
2. Если приложение ещё работает, деинсталлятор сам завершит трей, наблюдатель и
   исполнитель — отдельно закрывать их не нужно.
3. Приложение спросит, удалить ли сохранённые настройки подключения к розетке.
   - **Нет** — настройки останутся, повторная установка не потребует мастера.
   - **Да** — настройки удалятся; после установки нужно снова пройти раздел 3.
4. Ярлыки и автозапуск удаляются автоматически. Журналы сохраняются.

Если удаление запущено в тихом режиме (`/VERYSILENT`), настройки сохраняются
без вопроса; для удаления вместе с настройками — ключ `/DELETEAPPSETTINGS`.

---

## 7. Что не нужно делать

- Не устанавливать Python и не запускать скрипты вручную: всё уже внутри.
- Не копировать папку `app\secrets` и файл `tuya_plug.json` на другие
  компьютеры и не пересылать их: там ключ доступа к розетке.
- Не переносить программу в `Program Files`: она должна оставаться в
  `%LOCALAPPDATA%\Programs\OnAirLamp`.

---

## 8. Куда смотреть при проблемах

- **Пуск** → **OnAir Lamp** → **Если не работает** — быстрые шаги.
- **Пуск** → **OnAir Lamp** → **Отчёт для поддержки** — на рабочем столе
  появится `OnAirLamp-report-<дата>.zip` с журналами без ключей; этот архив и
  нужно отправить.
- Журналы вручную:
  `%LOCALAPPDATA%\Programs\OnAirLamp\app\data\work\meetings\` (`events.log`,
  `plug.log`).
