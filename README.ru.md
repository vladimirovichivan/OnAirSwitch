# OnAir Lamp

[English](README.md) | **Русский**

Лампа «On air»: умная розетка Tuya горит, пока идёт видеовстреча в Толке
(Teams), Телемосте или Zoom, либо пока вы в голосовом канале Discord, и гаснет,
когда звонок заканчивается. Всё работает локально:
облачный аккаунт в повседневной работе не нужен, права администратора не
требуются.

[**Скачать последнюю версию**](https://github.com/vladimirovichivan/OnAirSwitch/releases/latest)

## Как это работает

- Наблюдатель на PowerShell определяет окна встреч поддерживаемых приложений
  (а в Discord — захват микрофона во время звонка) и пишет события в локальный
  журнал. Устройством он не управляет.
- Отдельный исполнитель читает желаемое состояние, общается с розеткой по
  локальному протоколу Tuya и проверяет каждую команду повторным чтением.
- Значок в трее показывает текущую встречу и её длительность, состояние лампы и
  причину этого состояния; из меню можно включить или выключить лампу на срок
  или снять автоматику.
- Небольшой супервизор запускает и перезапускает все три процесса, поэтому
  упавший компонент поднимается сам.

Розетка опрашивается только когда нужна команда; если роутер выдал новый адрес,
он находится заново по UDP.

## Возможности

- Определение встречи по заголовкам видимых окон (Толк/Teams, Телемост, Zoom) с
  порогом в 3 замера, чтобы лампа не мигала; в Discord звонок определяется по
  захвату микрофона — заголовок окна там не меняется, а в трее окон нет.
- Локальный протокол Tuya; ключи хранятся только в локальном файле и никуда не
  отправляются.
- Ручные режимы: включить/выключить до срока, пауза автоматики, возврат в «Авто».
- Русский и английский интерфейс; по умолчанию — язык Windows.
- Мастер первой настройки, проверка розетки и отчёт для поддержки: журналы без
  ключей и идентификаторов устройства.
- Автопроверка обновлений через GitHub Releases; SHA-256 установщика сверяется
  до запуска.
- Установщик для Windows 10/11 (per-user, без UAC) и портативный ZIP.

## Требования

- Windows 10 или Windows 11 (64-бит).
- Совместимая умная розетка Tuya, добавленная в приложение Smart Life.
- Компьютер и розетка в одной локальной сети (не в гостевом Wi-Fi).
- Для Discord нужна настольная версия приложения (браузерная не определяется).
- Для сборки из исходников: Python 3.12 и, по желанию, Inno Setup 7 или 6.

## Установка

1. Скачайте `OnAirLamp-Setup-x.y.z.exe` со страницы
   [релизов](https://github.com/vladimirovichivan/OnAirSwitch/releases/latest).
2. Запустите установщик и оставьте включённым пункт «Запускать OnAir Lamp при
   входе в Windows».
3. При первом запуске приложение предложит мастер: введите ID устройства Tuya,
   local key и адрес (адрес можно найти по UDP).

Полная инструкция для получателя — [`docs/INSTALL.md`](docs/INSTALL.md) (она же
входит в установщик как `README.txt`). Если что-то не работает —
[`docs/SUPPORT.md`](docs/SUPPORT.md).

## Сборка из исходников

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup-dev.ps1
powershell -ExecutionPolicy Bypass -File packaging\build.ps1
```

Результат — в `build\`: портативная папка, ZIP-архив и, если найден Inno Setup,
`OnAirLamp-Setup-<версия>.exe`. Контрольные суммы — в `build\SHA256SUMS.txt`.

Для запуска при разработке используйте `packaging\start.vbs` или запускайте
компоненты вручную:

```powershell
.venv\Scripts\python.exe app\scripts\meetings\plug_executor.py --once
.venv\Scripts\pythonw.exe app\scripts\meetings\tray_plug.py
powershell -NoProfile -File app\scripts\meetings\watch_meetings.ps1 -Once
.venv\Scripts\python.exe app\scripts\meetings\tuya_setup.py --verify
```

## Приватность

- В повседневной работе приложение не открывает облачных соединений — только
  общается с розеткой в локальной сети.
- Ключи Tuya и local key лежат в
  `%LOCALAPPDATA%\Programs\OnAirLamp\app\secrets\tuya_plug.json` на вашем ПК.
- На время апробации заголовки окон пишутся в локальный журнал; в отчёт для
  поддержки не попадают ключи и идентификаторы устройства.
- Проверка обновлений отправляет один анонимный запрос к API GitHub Releases.
